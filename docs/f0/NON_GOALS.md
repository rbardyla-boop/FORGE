# FORGE F0 Non-Goals

The following are forbidden during the Foundation phase unless a later gate explicitly authorizes them.

1. Autonomous product management.
2. Autonomous roadmap generation.
3. Multi-agent swarm execution.
4. Adaptive model routing or AIS resource allocation.
5. Self-modifying Forge.
6. Automatic merge to `main` / `master`.
7. Automatic production deployment.
8. Generic support for every programming language.
9. A GUI or web dashboard.
10. Vector-database memory as a foundation dependency.
11. A new cognitive architecture.
12. LLAM/action-language redesign.
13. Automatic feature discovery or Powerplant Scout integration.
14. Rebuilding Powerplant, Cognitive OS, or StackVerdict wholesale.
15. Claiming "bug-free code."
16. Treating compilation, schema validity, a green unit test, or an AI self-review as general correctness.
17. Treating historical README/test claims as fresh Forge reproduction evidence.
18. Writing production code during F0.

## Deferred layers

### Walls
- builder adapter;
- Codex builder;
- independent verifier;
- GitHub protected-branch gate;
- bounded next-unit project manager.

### Roof
- multiple competing builders;
- specialist agents;
- Best-of-N;
- adaptive model selection;
- AIS;
- swarm orchestration;
- cross-project learned policies;
- self-improvement proposals;
- operator UI.
